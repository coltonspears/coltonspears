# Hi, I'm Colton

I build practical tools with C# and .NET and explore applied machine learning
with Python and PyTorch. I enjoy projects where I can build something useful,
measure how it behaves, and make it straightforward to run.

## Selected work

- **[Practical Image Sorter](https://github.com/coltonspears/practical-image-sorter)** —
  Train a small CNN on labeled folders, evaluate held-out results, and preview
  sorting decisions in a CSV. The included flower model reaches 91.01% accuracy
  on 556 test images, with baselines and a documented model card.
- **[Ultimate Tic-Tac-Toe ML](https://github.com/coltonspears/ultimate-tic-tac-toe-ml)** —
  A compact policy/value network, self-play training, PUCT search, and C# weight
  export. Includes trained weights, a CPU demo, and measured reference matches.
- **[UTT Arena Bot SDK](https://github.com/coltonspears/uttarena-bot-sdk)** —
  C# packages, a game protocol, sample bots, and a local testing harness for
  Ultimate Tic Tac Toe.
- **[PRdigest](https://github.com/coltonspears/PRdigest)** —
  Turn a GitHub pull request into a Markdown digest of discussions, changes,
  reviews, and checks for code review and AI-assisted workflows.

## Current interests
